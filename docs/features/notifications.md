# 🔔 Notifications

| | |
|---|---|
| **Notification bell** | Invites, message requests, @mentions, kicks and admin changes show up under the bell in the top bar. A site admin kicked by a group admin gets an Undo kick button, which puts them back as if it never happened |
| **Browser notifications** | Pop-ups for new messages, except from muted chats |
| **Message sound** | A short sound for new messages while HB Hub is open, also in a background tab, except from muted chats (turned on in settings) |
