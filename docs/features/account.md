# 🔐 Account & security

| | |
|---|---|
| **Profiles** | Profile picture, name, class and bio, plus a banner (two colors, or a JPEG XL picture that takes an attachment ticket and never runs out), a status (an emoji and up to 45 characters, which clears itself after 30 minutes to 7 days or never; click it on your own profile to change it, or "Click here to add a status!" to add one), an education badge and a Site admin badge. Message someone straight from their profile. A profile opened from a leaderboard (or the casino's top players) has a "Back to ..." link to it, sorted the same way. The class is 1., 2. or 3. year with a field of study (X, U, T, Y, Z), or Not HTX; the year goes up by itself every July 1st, and after 3. year it shows as Graduate |
| **Two-factor login** | TOTP codes from any authenticator app, set up with a QR code |
| **Discord login** | Link a Discord account and log in with it instead of the password (two-factor login still asks for the code). Sign-up's first step has "Sign up with Discord": it fills in the name, bio and picture from Discord (all still editable) and makes the account already linked; the rest of sign-up, password included, is the same. It can be linked or unlinked in the settings at any time. The linked Discord username is shown as a badge on the profile (a switch in the same card hides it, on by default) and is kept up to date: on every Discord login, and by the nightly job with `discord_bot_token` |
| **Login protection** | Password strength rules, a common-password list and lockout after failed attempts. Devices you've logged in on before have their own lock, so nobody can lock you out by guessing |
| **Logged in devices** | See every browser you're logged in on and when it was last used, log out any of them, or log out everywhere at once |
| **Self-blocking** | Block the Casino and Games pages during school hours (8 AM - 3 PM) or all the time. Turning a block off waits until school is over, or 6 hours for "All the time", so it can't be switched off in the moment. Site admins can also block both for someone from the admin panel, which only an admin can lift |
| **Home screen app** | HB Hub can be added to a phone's home screen and opens without the browser bars. The first page after logging in on a phone or tablet asks once (per browser) with a popup: a one-tap install button where the browser offers one (Chrome on Android), otherwise where to find Add to Home Screen |
| **Account deletion** | Delete your account and its data from the settings page |
| **Feedback** | The Feedback button at the bottom of the side bar sends bugs, ideas and wishes straight to the admins |
