# 🔐 Account & security

| | |
|---|---|
| **Profiles** | Profile picture, name, class and bio, plus a banner, picked in a Change banner popup: a gradient (two colors and a direction), a JPEG XL picture that takes an attachment ticket and never runs out, or a GIF from Giphy (searched like the chat's GIFs), a status (an emoji and up to 45 characters, which clears itself after 30 minutes to 7 days or never; click it on your own profile to change it, or "Click here to add a status!" to add one), an education badge and a Site admin badge. Message someone straight from their profile. Click a profile picture or banner picture on a profile to see it big. A profile opened from a leaderboard (or the casino's top players) has a "Back to ..." link to it, sorted the same way. The class is 1., 2. or 3. year with a field of study (X, U, T, Y, Z), or Not HTX; the year goes up by itself every July 1st, and after 3. year it shows as Graduate |
| **Settings page** | Laid out like a phone's settings app: a list of rows, each saying what it's set to and opening its own panel (side by side on a wide screen, taking turns on a phone), in four groups: Profile (picture and banner; name, class and bio; status), Preferences (notifications and sound, self-blocking, Attachments), Security (password, two-factor, Discord, logged in devices) and Account (Help improve HB Hub, log out and log out everywhere straight from their rows, delete). Each panel has its own address (/settings#block) and works without JS. Settings save by themselves as they're changed, with a Saving / Saved note on each panel; changing the password, two-factor and deleting the account still have their own buttons |
| **Two-factor login** | TOTP codes from any authenticator app, set up with a QR code |
| **Discord login** | Link a Discord account and log in with it instead of the password (two-factor login still asks for the code). Sign-up's first step has "Sign up with Discord": it fills in the name, bio and picture from Discord (all still editable) and makes the account already linked; the rest of sign-up, password included, is the same. It can be linked or unlinked in the settings at any time. The linked Discord username is shown as a badge on the profile (a switch in the same card hides it, on by default) and is kept up to date: on every Discord login, and by the nightly job with `discord_bot_token` |
| **Login protection** | Password strength rules, a common-password list and lockout after failed attempts. Devices you've logged in on before have their own lock, so nobody can lock you out by guessing |
| **Logged in devices** | See every browser you're logged in on and when it was last used, log out any of them, or log out everywhere at once |
| **Self-blocking** | Block the Casino and Games pages during school hours (8 AM - 3 PM) or all the time. Turning a block off waits until school is over, or 6 hours for "All the time", so it can't be switched off in the moment. Site admins can also block both for someone from the admin panel, which only an admin can lift |
| **Home screen app** | HB Hub can be added to a phone's home screen and opens without the browser bars. The first page after logging in on a phone or tablet asks once (per browser) with a popup: a one-tap install button where the browser offers one (Chrome on Android), otherwise where to find Add to Home Screen |
| **Straight to the chat** | Logged in users who open the frontpage are sent to the chat, and the HB Hub logo in the top bar goes there too. Double clicking the logo on the chat opens the frontpage (`/?home`) |
| **Help improve HB Hub** | Two switches in the settings (both on by default, but off from the start for an account made with a browser that sends Global Privacy Control or Do Not Track, which also gets a `settings.doNotTrack` notification saying so and why). **Error reports**: while it's off, no browser error (Watchdog) reports are sent and Ore Mining Inc. doesn't ask Chrome for its crash notes; Ore Mining Inc.'s own crash reports still ask first, with a warning that sending one overrides the setting for that report. **Anonymous usage statistics**: while it's off, their page views aren't counted for the admin Overview. It depends on Error reports: greyed out and off while Error reports is off. Accounts that turned off the old single switch (`improveSite`) have both off until they change them |
| **Account deletion** | Delete your account and its data from the settings page |
| **Feedback** | The Feedback button at the bottom of the side bar sends bugs, ideas and wishes straight to the admins |
