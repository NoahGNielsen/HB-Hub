# 🎲 Games

## Matador

| | |
|---|---|
| **Matador** | The Danish Monopoly for 2-4 players. Games can be public, joined with a 6-character code, or invite-only |
| **House rules** | One dice (a 6 gives another roll), no auctions: a property nobody buys stays with the bank. Get out of jail by paying, using a "benådet" card or rolling a 6. Taxes and Prøv lykken payments go into Parkering's account, and whoever lands on Parkering gets it (a room setting, on by default). The host can also let players build houses and hotels on any street they own, without the whole colour, or build with the whole colour but not evenly (both off by default) |
| **Full game** | Houses and hotels, mortgages, Prøv lykken cards, the income tax choice, and trading properties, money and cards with the other players at any time |
| **Turn timer** | 30 seconds to act, reset by every move. Run out and your turn is passed on. The timer pauses while you owe money, and the host can pause the whole game |
| **Saves** | The game saves after every move. Leave and your seat is kept for you. The host can give an empty seat to someone else, or save and stop the game to continue it later |
| **Leaving** | Leaving a game being played (or having it closed for 60 seconds) counts as a loss on the leaderboard straight away, even if you come back, unless the host has paused the game |
| **In-game chat** | A chat for each game, plus a sound when it's your turn |

## Chess

| | |
|---|---|
| **Chess** | Two-player chess with every rule: castling, en passant, promotion (only to a piece your opponent has taken from you; until then a pawn waits on the last rank, and the choice pops up the moment one is taken), and draws by stalemate, repetition, the 50-move rule and too few pieces. Public, code or invite-only games, with or without a clock (3+2 up to 30 minutes), set in the game's settings. The host starts the game once someone has joined |
| **Chess extras** | Draw offers, resigning, aborting before both have moved, claiming the win when your opponent has gone, leaving losing the game (unless the host has paused it; if both players are gone too long it's a loss for both), the host pausing the game (and the clocks), rematches with swapped colours, arrows and highlighted squares drawn with the right mouse button (like chess.com), an in-game chat and a leaderboard |

## UNO

| | |
|---|---|
| **UNO** | The card game for 2-6 players, with the full 108-card deck: numbers, Skip, Reverse, Draw Two, Wild and Wild Draw Four (which can be played at any time). Public, code or invite-only games. The host starts the game once someone has joined, and a new one when it's over; new players can join between games |
| **Several cards at once** | Cards with the same number or symbol can be played together, any colour: click the one that fits, then the others in the order you want, and press Play. The last one decides the colour, and every card counts (two Skips skip two players, two Draw Twos make 4). Not for wild cards or a card just drawn |
| **Calling UNO** | Press UNO! when you play your second-to-last card. Forget, and anyone can catch you before the next player moves: you draw 2 |
| **Settings** | The host picks the time for a turn (15, 30 or 60 seconds), stacking (off, same card only - a Draw Two on a Draw Two, a Wild Draw Four on a Wild Draw Four, to pass them all on - or any draw card, where a Wild Draw Four can also go on a Draw Two and the other way round; any draw card by default) and drawing until you can play (off by default: you draw one card), in the game's settings |
| **Turn timer** | Run out of time and you draw a card (or the cards waiting for you), and your turn is over. The host can pause the game |
| **Leaving** | Leaving a game being played (or having it closed for 60 seconds) takes you out of it and counts as a loss, unless the host has paused the game. Your cards go back into the deck, and the last player left in wins |
| **Extras** | Official scoring (the winner scores the cards left in everyone else's hands), a log of what happened, an in-game chat with @mentions, a sound when it's your turn, and a leaderboard with wins, win %, points and best win |

| | |

There's an English and a Danish word every day (the Danish keyboard has æ, ø and å), the same for everyone, with stats, sharing and a leaderboard for each language with win %, average guesses and the current and longest streak |

## Free games without an account

| | |
|---|---|
| **/play** | Wordle and Ore Mining Inc. (and the casino games, see [Casino](casino.md)) can be played without an account at `/play/wordle` and `/play/ore-mining-inc`, listed on `/play`, in the sitemap and `llms.txt` and with their own titles, descriptions and structured data for search engines. The normal versions still need an account: logged-in visitors are sent to them, and a browser that has ever logged in (it has the `hbHubDevice` cookie) is sent to the login and then to them. The free games' back link goes to the frontpage |
| **Saving** | Nothing about a guest is stored on the server: the game is kept in the browser as a token encrypted and signed with the site key (`guest_games_secret`), sent with every guess or save and checked with the same rules as the normal game. Guests get no stats, leaderboards or crash reports |
| **Signing up** | A bar on top of each free game, and a popup after 3 minutes of play (then every 10 minutes, and when a Wordle is finished), asks the visitor to sign up or log in. Doing that leads to the normal game, which brings today's Wordle games and the Ore Mining Inc. save over to the account, but only where it has none yet |

The Games section can be opened to everyone, only to admins, or to nobody with `games_access` in the
[config](../config.md), and players can block it for themselves (see [Account & security](account.md)). The free games are only open while it's open to everyone.
